# 本机实际验收说明

验收日期：2026-11-14（北京时间）。环境为 Windows 11、完整版 AutoCAD 2026（25.1）、.NET 8、Node.js 24.15 和 Python 3.13。

这是开发机器上的实际验收记录，不表示已验证所有 AutoCAD 版本、所有电脑或所有几何输入。

## 结果

- 完整工具回归：107 次调用，无失败。

- 加上最终支架和视图验收，共 248 次调用，全部 93 个工具均至少成功调用一次，见 [覆盖统计](test-coverage.json)。
- 4 项参数规则单元测试通过。
- 实际验证计划执行、错误停机、禁止重放、步骤间取消、事务回滚、恢复点、重复项清理、轮廓修复和撤销。
- Codex 配置已在开发机器注册，工具发现及真实调用使用官方 MCP Client 完成。其他机器必须按 README 安装。

## 示例模型

底板 120×80×8 mm；后侧支撑板 120×8×60 mm，从底板上表面起算，总高度 68 mm。最终一个原生 Solid3d，体积 130586.08881569224 mm³，与理论值 `134356 − 1200π` 在 1e-5 mm³ 比较容差内一致。该容差是算例核验阈值，不是制造精度承诺。

未指定尺寸采用以下明确假设：底板四孔中心距边 15 mm；后壁位于 Y=72..80；支撑板两孔直径 10 mm，中心 X=35/85、Z=38、孔轴沿 Y；两个外侧边做 1×1 mm 倒角。需求中另一个仅底板示例给定 12 mm 孔距，执行该示例时必须保留 12 mm。

六个孔分别使用半径 4.99/5.01 mm 的实体探针进行独立内核干涉检查，前者不相交，后者相交，共 12 次检查通过。探针检查后删除。保存、关闭、重新打开 DWG 后再次检查尺寸、实体数量和体积。

## 文件核验

- DWG：通过 AutoCAD 重新打开检查。
- STL：634 个三角面，所有边恰好属于两个三角形，网格闭合；包围尺寸误差不超过 1e-4 mm。网格体积相对原生体积误差约 0.03286%，来自三角近似，精确编辑源为 DWG。
- PDF：1 页，解析并渲染检查，329 个矢量路径。
- 最终建模录像：H.264，1920×1080，60.9 秒。桌面录像留在开发机器，不随公开仓库发布。

示例目录附 [孔检查](../examples/bracket/hole-verification.json)、[重开检查](../examples/bracket/reopened-verification.json) 和 [文件核验](../examples/bracket/file-verification.json)。完整运行日志留在开发机器；可运行仓库测试脚本在自己的机器生成新的日志和录像。
